# Smart Spend Hub 💰

A personal finance management web application designed to help users track income and expenses, manage monthly budgets, monitor savings, and understand their spending patterns through interactive dashboards.

## 🌐 Live Demo

[Open Smart Spend Hub]
(https://smart-spend-buddy-987-cm1o-mkcuo9bo4-yyy-7a49.vercel.app/)

## 📌 Overview

Smart Spend Hub provides a simple and user-friendly platform for managing personal finances in one place.

The application allows users to record their financial transactions, monitor their current balance, set monthly budgets, and analyze their spending through visual dashboards.

The goal of the project is to make everyday financial tracking easier and help users understand where their money is going.

## ✨ Features

- 📊 **Dashboard**
  - Total income
  - Total expenses
  - Current balance
  - Monthly budget
  - Remaining budget
  - Savings overview

- ➕ **Add Transaction**
  - Add income and expense transactions
  - Select transaction categories
  - Enter transaction amount and details

- 📜 **Transaction History**
  - View recorded transactions
  - Track income and expenses
  - Review previous financial activity

- 💰 **Budget Management**
  - Set monthly spending limits
  - Monitor remaining budget
  - Compare expenses against the planned budget

- 📈 **Analytics**
  - Monthly spending trends
  - Spending category breakdown
  - Visual representation of financial activity

- 📱 **Responsive Interface**
  - Clean and simple user interface
  - Designed to work across different screen sizes

🚀 Getting Started
Prerequisites
Make sure you have the following installed:
Node.js
npm

Installation
Clone the repository:
git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project directory:
cd smart-spend-hub
Install dependencies:
npm install
Start the development server:
npm run dev
The application will then be available on the local development server.
